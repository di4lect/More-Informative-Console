# Vampire Eye Glow Fix (SKSE)

Removes the emissive glow that Dawnguard bakes into vampire eye shapes (and into every vampire NPC's FaceGen head),
at runtime, as actors load. No FaceGen, mesh or plugin edits.

Install: `SKSE/Plugins/VampireEyeGlowFix.dll` + `VampireEyeGlowFix.ini`. Requires SKSE and Address Library.
One DLL for SE 1.5.97, AE 1.6.x and VR. See the ini for options (vampires only vs. every glowing eye, optional faint glow).
